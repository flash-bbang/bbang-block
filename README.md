# 빵빵 블록 (BBANG BLOCK)

식빵 블록을 끌어다 8×8 오븐 판에 채우고, 가로나 세로 한 줄이 차면 빵! 하고 터지는 퍼즐 게임.

- 플레이: https://flash-bbang.github.io/bbang-block/
- 만든 곳: flash.bbang (https://flash-bbang.github.io/space-xxx/ 도 해보세요)

## 특징
- 살아있는 식빵: 판이 차면 겁먹고, 게임이 끝나면 새카맣게 탐
- 사장님 식빵이의 잔소리
- 비둘기 똥 습격 (줄로 지우면 +30점), 황금빵 (점수 두 배)
- 이어하기 자동 저장, 닉네임·온라인 순위·기록 공유

## 온라인 순위
SPACE XXX와 같은 Firebase 프로젝트(space-xxx)의 `block_scores` 컬렉션을 씁니다.
보안 규칙은 Firebase 콘솔의 Firestore 규칙에서 관리합니다.
